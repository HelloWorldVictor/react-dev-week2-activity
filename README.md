# Week 2 React TypeScript Activity

A small React application built with TypeScript and Vite. It demonstrates how
to create a reusable component and style it with a separate CSS file.

## Run Locally

```bash
npm install
npm run dev
```

## Verify the Project

```bash
npm run lint
npm run build
```

The main component is `src/MyComponent.tsx`. It is imported into `src/App.tsx`
and styled in `src/MyComponent.css`.
